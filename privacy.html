Jarvis privacy policy

Jarvis is a personal assistant used by one person, its owner, on the owner's own computer.

What data it accesses

Only the owner's own Google account data that the owner approves on the Google consent screen: Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets and Google Tasks.

How the data is used

The data is used only to carry out the owner's own requests (for example reading mail, creating drafts, listing events or finding files). It is not sold, shared with third parties, used for advertising, or used to train models.

Where the data is stored

Access tokens are stored only on the owner's computer. Jarvis keeps no copy of Google data on any server.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
